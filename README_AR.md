بوت أتمتة متطور وآمن كلياً ومخصص للعبة **Clash of Clans**. يعتمد بالكامل على تقنيات الرؤية الحاسوبية الديناميكية (**محرك OpenCV لمطابقة القوالب بمقاييس متعددة لكافة الشاشات**) وقراءة النصوص بالذكاء الاصطناعي (EasyOCR). يعمل البوت بشكل خارجي وآمن 100% عبر واجهة Android Debug Bridge (ADB) لمحاكاة نقرات اليد ولقطات الشاشة على **جميع الأجهزة والتابلت (4:3 و 16:10) والهواتف الذكية والمحاكيات وشاشات 4K** دون الحاجة للتعديل على ملفات اللعبة أو حقن ذاكرتها.

## 🎮 ما هو هذا البوت؟ (للاعبين والمستخدمين)

هل مللت من قضاء ساعات طويلة يومياً في الهجوم وجمع الذهب والإكسير لتطوير قريتك؟ هذا البوت يعمل **كمساعد افتراضي متكامل** يلعب اللعبة بدلاً منك على جهاز الكمبيوتر الخاص بك عبر الأجهزة الحقيقية أو محاكيات الأندرويد تماماً كأنك أنت من تلعب.

### 🌟 أهم مميزات البوت للاعبين
* **📱 دعم شامل لجميع المقاسات والأجهزة (Dynamic Multi-Device):** يستعلم البوت تلقائياً عن أبعاد الشاشة (`wm size`) والكثافة (`wm density`) عبر ADB، ويتكيف تلقائياً مع التابلت (4:3 و 16:10)، الهواتف الحديثة، والمحاكيات (LDPlayer, BlueStacks) بدون أبعاد ثابتة.
* **🖼️ صورة مرجعية واحدة لجميع الأجهزة (Universal Single-Template):** طقم قوالب صور واحد يعمل بمرونة على كافة الأجهزة والشاشات وخلفيات القرى المختلفة (الخلفيات الداكنة، الثلجية، والغابات). لا داعي لإعادة تصوير أي زر يدوياً!
* **⚡ 5 بروفايلات أداء مخصصة والبروفايل الذكي:** يحتوي البوت على 4 بروفايلات جاهزة (`Ultra`, `High`, `Medium`, `Low`) + `البروفايل الذكي التلقائي` المربوط بزر **Reset to Default**، والذي يقرأ مواصفات جهازك وأبعاد الشاشة ويعدل السرعات والدقة تلقائياً.
* **🛡️ معالجة الأجهزة واللابتوبات الضعيفة:** حماية كاملة من انهيارات OpenCV والتحويل الآمن التلقائي لمعالج EasyOCR من GPU إلى CPU للأجهزة الضعيفة ذات المعالج ثنائي النواة.
* **🛡️ تجاوز مستويات المقاتلين وتغير الأشكال (Level Invariance):** دمج مطابقة الحواف `Sobel` مع اقتصاص ملامح المقاتلين المركزية لتجاهل تغيرات نجوم وإطارات الترقية.
* **البحث التلقائي وتصفية الغنائم (Loot Filter):** يقرأ البوت كميات الذهب والإكسير المتاحة في قرية الخصم. إذا كانت الموارد أقل مما حددته، يتجاوز القرية تلقائياً ويبحث عن قرية أغنى.
* **الهجوم التكتيكي والإنزال الذكي:** يقوم بإنزال القوات والأبطال وتوزيع المشروبات السحرية بناءً على خوارزميات ذكية تتجنب المناطق الحمراء وتصنع مسارات تقدم منظمة.
* **التدريب التلقائي للجيش:** يكتشف البوت خلو المعسكرات، ويفتح نافذة التدريب وتدريب التشكيلات الجاهزة.
* **تفعيل قدرات الأبطال تلقائياً:** يراقب البوت طاقات الأبطال ويفعل مهاراتهم عند الحاجة.
* **أتمتة قرية البناء (Builder Base) بالكامل:** هجوم على مرحلتين والانتقال التلقائي للقرية الثانية.
* **منع التعليق وإعادة التشغيل (Anti-Stuck):** يتجاوز انقطاع الإنترنت وينقر زر "Reload" للتأكد من العمل 24/7.

## ⚡ نظام البروفايلات الـ 5 للأداء

| البروفايل | الأجهزة المستهدفة | الخصائص |
| :--- | :--- | :--- |
| ⚡ **Ultra** | الأجهزة القوية بكروت شاشة منفصلة وشاشات 2K/4K | أقصى سرعة، فحص 0.5 ثانية، 4 وحدات OCR. |
| 🔥 **High** | لابتوبات الألعاب والأجهزة المتوسطة العالية | أداء سريع وموثوق، فحص 0.8 ثانية. |
| 💻 **Medium** | أجهزة المعالج العادي بدون كرت شاشة منفصل | أداء متوازن ومناسب لمختلف الأجهزة. |
| 🐢 **Low** | اللابتوبات والأجهزة الضعيفة جداً | خفيف وآمن جداً مع نمط CPU لـ OCR. |
| 🤖 **Smart Default** | جميع الأجهزة والتابلت والمحاكيات | **يكتشف المواصفات والأبعاد تلقائياً** (مربوط مع Reset to Default). |

## 🚀 دليل التثبيت والتشغيل

### الخطوة 1: تنزيل الملفات
```powershell
git clone https://github.com/alisakkaf/Clash-of-Clans-Bot-Auto-Farmer.git
cd Clash-of-Clans-Bot-Auto-Farmer
```

### الخطوة 2: البيئة الافتراضية
```powershell
python -m venv venv
venv\Scripts\activate
```

### الخطوة 3: تثبيت المكتبات
```powershell
pip install --upgrade pip
pip install -r requirements.txt
```
